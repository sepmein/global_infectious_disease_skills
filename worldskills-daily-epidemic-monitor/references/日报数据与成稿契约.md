# 日报数据与成稿契约

## 运行输入

- `monitor_date`：日报监测日，使用 ISO 日期。
- `participants`：本次运行开始时从同目录 [`参赛国家和地区名单.csv`](参赛国家和地区名单.csv) 读取的国家/地区代码、英文名称、中文标准名称动态名单；不得使用旧交付物替代。
- `priority_diseases`：本次运行开始时从同目录 [`重点病种检索配置.csv`](重点病种检索配置.csv) 读取的重点病种动态配置；不得使用旧交付物替代。
- `previous_event_ledger`：前一日已核实事件和来源快照；首次运行可为空。

## 事件记录最小字段

| 字段 | 说明 |
| --- | --- |
| event_key | 稳定事件标识，用于每日关联和去重。 |
| 国家/地区 | 与运行名单一致的中文标准名称及代码。 |
| 疾病 | 标准中文名，必要时标明病原体或亚型。 |
| 发生地区 | 来源中披露的行政区或“未分列”。 |
| 事件性质 | 新发、暴发、异常上升、持续高负担、扩散或高病死率。 |
| 病例和死亡 | 原始口径、数值及统计期间；不同来源不可相加。 |
| 信息日期 | 发布日期或数据截至日期。 |
| 来源 | 机构、标题、URL、访问日期和核实状态。 |
| 日间变化 | 新增、病例增加、死亡增加、地区扩展、状态变化、无显著变化或待审核。 |

## 配置读取失败

国家/地区名单或重点病种配置任一项无法读取、为空或无法解析时，不生成疫情结论、Word 日报或正式事件台账。可交付一份运行失败说明，列出失败原因，等待配置恢复或由任务方提供明确的替代输入。

## Word 格式

- 标题：二号方正小标宋简体，居中，单倍行距。
- 正文：三号仿宋 GB，首行缩进 2 字符，固定 27 磅行距，段前段后 0。
- 一级标题：三号黑体；二级标题：三号楷体 GB 加粗；三级标题：三号仿宋 GB。
- A4 页面，上下左右页边距均为 28 mm。
- 在“附：主要信息来源”中列出每个日报事实对应的国家/地区、病种、日期、机构和原文 URL。

## 日报口径

总体概况总结监测期内的重要信号，不逐一罗列所有国家。新增动态仅包括较前一日新增或发生实质变化的已核实事件；当日没有符合条件的变化时，明确写“当日未发现新增或明显变化的已核实重要疫情动态”。这不构成无疫情结论。
