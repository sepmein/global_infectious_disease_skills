# WorldSkills Daily Epidemic Monitor

用于赛事相关国家和地区的境外传染病每日监测及中文日报初稿，不用于个体诊疗或替代公共卫生专业审核。

## 运行前

在每次运行开始时，重新读取本技能目录下的两份权威配置文件：[`references/参赛国家和地区名单.csv`](references/参赛国家和地区名单.csv) 和 [`references/重点病种检索配置.csv`](references/重点病种检索配置.csv)，再读取监测日期、前一日事件台账和输出目录。名单和病种均为运行时输入，不得硬编码国家数、国家名称或病种名单；不得从旧日报、旧台账、示例文件或脚本常量回填配置。

配置文件无法读取、内容为空或格式无法解析时，停止交付并明确报告缺少的输入；不得静默沿用上次运行的配置。若没有前一日台账，明确本次为基线运行，只生成完整事件库，不把所有发现写成“当日新增”。

详细字段和成稿格式见 [日报数据与成稿契约](references/日报数据与成稿契约.md)。

## 采集与核实

1. 逐国优先访问国家卫生主管部门、国家 CDC、公共卫生机构和法定监测系统；再使用 WHO、ECDC、PAHO、Africa CDC 等国际或区域机构发现和交叉核验信号。
2. 对每个重点病种建立本轮术语记录：标准中文名、官方英文名、别名、缩写及该国机构常用语种词。国家官方语言检索至少覆盖本地官方语种与英文，不把搜索摘要当作证据。
3. 保留原始页面 URL、来源机构、标题、发布日期或数据截至日期、访问日期、原文摘要和访问状态。媒体只能作为线索；未取得原始官方来源时，标记为待核实，不写入已核实事件数据或风险排序。
4. 仅保留具有新发、暴发、异常上升、持续高负担、扩散、高病死率或明显赛事相关性的事件。没有读到可核实事件表示“本次未发现符合纳入阈值的证据”，不表示该国无疫情或零病例。

## 事件台账与日间比较

为每个事件保存稳定事件键，至少含国家/地区、疾病、发生地区、首报或监测期、来源 URL 和数据口径。将同一事件的多来源记录归并，保留全部来源但不累加不同口径的病例或死亡数。

与前一日台账比较后，只有以下变化进入“当日新增疫情动态”：新事件、病例或死亡数显著增加、新增受影响地区、病原或亚型首次确认、传播状态改变、暴发开始或结束。无法可靠匹配时，标为“可能更新，需人工审核”，不擅自合并。

## 交付

生成可编辑 Word 日报初稿及可追溯的事件台账。Word 只写证据支持的内容，并保留以下章节：

1. `一、近期赛事相关国家和地区疫情总体概况`
2. `二、当日新增疫情动态`
3. `三、对上海市传染病输入风险综合研判`
4. `附：主要信息来源`

对上海的研判应区分疫情事实与风险推断，综合人员往来、传播方式、季节、本地传播条件和证据不确定性。不得把示例文本、历史日报或未核实媒体信息写成当天事实。

Word 采用 A4，左右页边距 28 mm，正文三号仿宋 GB、固定 27 磅行距；标题和层级按日报契约执行。生成后执行 Word 渲染检查；渲染依赖不可用时，报告结构检查结果及未完成的视觉检查，不得声称已完成视觉核验。

## 结束条件

交付前检查：事件均能回溯至来源台账；来源链接、日期和数字不跨来源拼接；新增事件确实相对前一日发生变化；日报和台账的国家、疾病、病例、死亡和日期一致。保存当天台账和历史版本，以支持后续连续监测。
