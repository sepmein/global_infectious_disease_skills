# 中心院公文版式

本规范仅作为 `daily` 模式的通用公文参考，或用于用户明确要求的其他公文报送版。`baseline` 摸底报告不使用本规范作为版式依据，必须严格复刻 `../assets/世界技能大赛传染病疫情摸底报告_写作模板.docx`。生成日报时必须先读取 [../日报规范.md](../日报规范.md)，两者冲突时以 `日报规范.md` 为准。Excel 证据底表继续使用适合筛选、核查和追溯的电子表格版式，不套用公文排版。

## 正式成文所需字段

- `addressee`：主送单位全称。
- `issuing_organization`：落款中的发文单位全称。
- `document_date`：成文日期，默认使用报告日期或摸底截止日期。
- `attachment_names`：存在附件时按顺序列出完整名称。
- `annotation`：存在附注时提供内容，不含外层圆括号。

上述字段只适用于用户明确要求的公文报送版。普通 `daily` 报告和固定模板的 `baseline` 摸底报告默认不设置主送单位和文末落款。需要这些字段但无法从用户提供的正式模板中可靠读取时不得杜撰，应先向用户确认；仍未取得时只能生成标明“送审稿”的非正式文件，并在交付校验中记录缺口。

## 页面

- 左、右页边距均为 28 mm。
- 上、下页边距沿用用户提供的 DOCX 模板；没有可读取模板时使用适合公文打印的稳定值，并在生成后逐页检查。
- 正文使用纵向页面。宽表优先拆表或移入 Excel；确需横向页时使用独立分节，不得缩小整篇正文以迁就单个表格。

## 标题

- 报告标题使用 2 号方正小标宋简体，即 22 pt。
- 单倍行距，居中，不加粗，不使用下划线、边框或装饰线。
- `baseline` 报告主标题居中编排，不适用正文层级标题“前空两格”的要求；`daily` 标题按 [../日报规范.md](../日报规范.md) 在文字前保留两个全角空格。
- 标题与主送单位之间空一行。
- 若系统缺少方正小标宋简体，仍在 DOCX 中明确设置该字体名称，并在交付说明中提示渲染器可能替换字体；不得静默换成无关字体。

## 主送单位

本节不适用于普通 `daily` 报告；用户明确要求公文报送版时除外。

- 写单位全称，以全角冒号结束。
- 居左顶格，不缩进。
- 位于标题后空一行的位置。
- 正文从主送单位下一行开始。

## 正文

- 正文字体为 3 号仿宋 GB，优先使用字体名 `仿宋_GB2312`，字号 16 pt。
- 普通正文段首行缩进 2 个汉字。优先在 OOXML 中设置 `w:firstLineChars="200"`，不要用空格模拟缩进。
- 回行顶格，两端对齐。
- 行距为固定值 27 pt。OOXML 对应 `w:spacing w:line="540" w:lineRule="exact"`。
- 段前、段后均为 0 pt。
- 病例数、死亡数、日期、风险等级和来源编号不得因排版需要被改写或省略。

## 正文结构层次

- 一级标题：`一、二、三、`，3 号黑体，16 pt，不额外加粗，不加句号。
- 二级标题：`（一）（二）（三）`，3 号楷体 GB，优先使用 `楷体_GB2312`，16 pt，加粗。
- 三级标题：`1. 2. 3.`，3 号仿宋 GB，16 pt。数字与标题文字之间不额外插入项目符号。
- 一级、二级、三级标题前均空两格。优先在 OOXML 中设置 `w:firstLineChars="200"`，不得输入两个空格字符模拟。
- 各级标题段前、段后为 0 pt，固定行距 27 pt；按公文层次使用，不用 Word 自动项目符号替代标题编号。

## 表格

- Word 正文表格文字默认使用 3 号仿宋 GB，表头可使用 3 号黑体，但黑体表头不额外加粗。
- 不得为了放入宽表擅自把文字缩小到 3 号以下。优先减少非必要列、拆分表格、使用横向分节，或将完整明细保留在 Excel。
- 表格首行必须设置为可重复表头，并通过 documents Skill 的可访问性检查。
- 长网址和完整本地路径原则上放入 Excel 来源登记；Word 只保留审核所需的规范来源名称、日期、Source ID、Event ID 和可点击原始 URL。

## 附件

- 正文结束后空一行编排附件说明。
- 附件说明使用 3 号仿宋 GB。格式示例为 `附件：1. ××××`。
- 多个附件逐项编号。附件标题换行时，与上一行附件名称的首字对齐。
- 附件说明与落款之间空三行。
- 每个附件首页左上角顶格标注 `附件1`、`附件2`，使用 3 号黑体且不额外加粗。该附件顺序标识保持顶格，不属于正文层级标题。附件正文版式与主文正文相同。
- 没有附件时不生成空的“附件”占位。

## 落款和成文日期

本节不适用于普通 `daily` 报告；日报日期按 [../日报规范.md](../日报规范.md) 置于标题下方。用户明确要求公文报送版时除外。

- 落款包含发文单位和成文日期，不得虚构单位名称。
- 成文日期使用中文完整年月日，月份和日期不补零，例如 `2026年9月7日`，不得写成 `2026年09月07日`。
- 成文日期一般右空四字编排。使用段落右缩进或制表位实现，不用连续空格模拟。
- 发文单位与成文日期的对齐方式应保持稳定，并在逐页渲染中检查。

## 附注

- 附注位于成文日期下一行。
- 使用圆括号包围，居左空二字编排，例如 `（联系人和发布范围说明）`。
- 没有附注时不生成空括号。

## 生成和检查

1. 使用 documents Skill 创建 Word，并在生成逻辑中明确设置中文字体的 `w:eastAsia` 属性。
2. 运行 `scripts/validate_deliverables.py --require-official-format` 检查页边距、标题、正文、层级标题、主送单位、落款和日期。
3. 使用 documents Skill 渲染为逐页 PNG，检查字体替换、分页、表格、附件换行、落款位置和附注缩进。
4. 缺少指定字体或无法完成渲染时，文件只能标为送审稿，并明确披露未完成的版式检查。
