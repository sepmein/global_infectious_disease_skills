# 发布门槛

## 数据门槛

- 名单和重点病种配置校验通过，报告中的国家数由本轮名单动态生成。
- 每个名单条目恰有一条 Coverage 记录，且不存在 `NOT_CHECKED`。
- 所有纳入事件至少有一个非 D 级来源；精确病例和死亡数字可回到明确的原始位置和统计截止日。
- Source_ID、Event_ID 和 Observation_ID 唯一且引用完整。
- 本地来源有 SHA-256；有原始 URL 时同时保留原始 URL 和本地路径。
- 所有重叠候选都有复核决定；冲突没有被平均或静默删除。

## 日报门槛

- Word 日报已读取并符合 [../日报规范.md](../日报规范.md)。
- “当日新增及变化疫情动态”只包含变化检测结果中的实质变化。
- 总体概况中的重点疫情均在“当日新增及变化疫情动态”中有对应内容。
- “其他未更新传染病疫情”按国家或地区和疾病名称列明。
- “附：信息来源”另起一页并覆盖正文全部疫情数据。
- 首期无历史数据时明确标为基线，不伪造前一日变化。
- 上海风险研判分别说明输入可能性、本地传播可能性和公共卫生影响。
- 无实质变化时使用“未发现符合报告阈值的新变化”，不写“无疫情”。

## 摸底报告门槛

- 逐国覆盖记录数等于动态名单数。
- Word、Excel 和标准化证据中不存在 `participants.csv` 之外的国家或地区，不存在 `priority-diseases.xlsx` 之外的疾病。
- 每个纳入疾病的分类与 `priority-diseases.xlsx` 的“所属分类”完全一致。
- 每个疾病的“疾病概述”均按 `disease-intro-index.csv` 记录了 `疾病简介/` 中采用的对应文档；只有映射文件指定的文档确实缺失时，才允许使用互联网疾病简介，并记录缺失状态和替代来源。
- 全球流行概况、重点国家流行情况、趋势、医疗负担和风险因素中，本地资料不足的内容已经实时检索并由可核验的官方网络来源补足。
- 重点国家不超过 10 个，均来自名单和经核验事件。
- Word、Excel、来源登记和网络证据清单的病例、死亡、日期及来源一致。
- 国家级资料缺失、官网受限和未形成经核验信号分别记录，不相互替代。
- Word 从 `../assets/世界技能大赛传染病疫情摸底报告_写作模板.docx` 派生，保留模板结构和版式，且没有残留说明文字、虚构示例或占位内容。
- 每个纳入疾病均完整包含“疾病概述、全球流行概况、重点国家流行情况、风险因素”四部分。

## 文件门槛

运行：

```bash
python scripts/validate_deliverables.py --mode <daily|baseline> --participants <名单> --diseases <重点病种表> --docx <报告> --xlsx <底表> --require-official-format
```

`daily` Word 必须符合 [../日报规范.md](../日报规范.md)；`baseline` Word 必须符合 [baseline-report.md](baseline-report.md) 并严格复刻 `../assets/世界技能大赛传染病疫情摸底报告_写作模板.docx`。两类 Word 均按 documents Skill 渲染为逐页 PNG 检查全部页面；Excel 必须按 spreadsheets Skill 检查公式错误、筛选、冻结表头、列宽、换行和所有工作表。任何校验失败时不得称为正式报告。

正式 Word 还必须满足以下通用要求：

- 左右页边距均为28 mm；
- 标题为2号方正小标宋简体、单倍行距；
- 普通正文为3号仿宋GB、首行缩进2字符、固定行距27 pt、段前段后0 pt、两端对齐；
- 一级、二级、三级标题的字体和字号符合公文层级，标题前空两格；一级标题及其他黑体文字不额外加粗；
- 有附件或附注时位置、字体、缩进和间距符合模板，没有时不保留空占位。

`daily` Word 还必须满足：标题文字前保留两个全角空格；标题下方使用括号日期；不设置主送单位和文末落款；“附：信息来源”另起一页；不保留批注、修订、删除线或高亮。

`baseline` Word 还必须满足：摸底时间、摸底范围、重点国家表、四类疾病标题和逐病种四部分结构均保留；模板未设置主送单位、落款或成文日期时不得擅自添加。
