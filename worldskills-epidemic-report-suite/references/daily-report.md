# 每日监测日报模式

## 目标

日报不是当天所有疫情记录的重排，而是“背景概况 + 相对上一期的实质变化 + 上海风险研判”。首期没有历史观测时，先建立基线，并明确无法进行前一日比较。

## 实质变化

运行 `scripts/detect_daily_changes.py`，仅将以下变化写入“当日新增疫情动态”：

- 新事件首次出现；
- 病例或死亡增加；
- 新增传播地区；
- 事件状态变化，例如暴发宣布、结束或风险等级调整；
- 病原体首次确认或重要分型变化；
- 官方修订导致的病例口径或结论变化。

只有发布日期变化、网页重新发布、措辞微调或相同快照被另一个渠道抓取，不属于实质变化。

## Word 结构

生成本模式 Word 前必须读取并执行 [official-document-format.md](official-document-format.md)。主送单位、正文、标题层级、附件、落款、日期和附注均按中心院公文版式编排。

1. 标题：`世界技能大赛相关国家传染病疫情监测日报`。
2. `一、近期赛事相关国家和地区疫情总体概况`：概述背景窗口内高发、暴发、异常上升、新发少见或国际旅行相关事件，不逐国罗列。
3. `二、当日新增疫情动态`：只写本轮新发现或明显变化的事件。无实质变化时写“本轮未发现符合报告阈值的新变化”，不得写“未发生疫情”。
4. `三、对上海市传染病输入风险综合研判`：按 [shanghai-risk.md](shanghai-risk.md) 区分输入可能性、本地持续传播可能性和公共卫生影响。
5. `附：主要信息来源`：列明国家/地区、疾病、发布日期或统计截止日、来源机构、原始 URL、访问日期、Event_ID 和 Source_ID。

“附：主要信息来源”是报告内容组成部分，不自动等同于公文附件。只有用户提供 `attachment_names` 或确有独立附件文件时，才在正文后编排公文“附件”说明。

## 支持底表

Excel 至少包含：`当日变化`、`经核验疫情底表`、`来源登记`、`检索覆盖记录`、`重叠与冲突`。完整证据保留在底表，Word 只呈现需要审核的重点内容。
