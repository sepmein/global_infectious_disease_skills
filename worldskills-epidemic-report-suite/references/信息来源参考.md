# 信息来源参考

以下来源类型可作为逐国实时检索的候选来源。它们仅用于确定检索方向，不构成历史事件证据，也不能替代本轮实际访问并核实的原始页面。

## 优先来源

1. WHO：Disease Outbreak News、区域形势报告、疾病专题页和正式数据产品。
2. 各个国家卫生主管部门：卫生部、卫生服务部门、公共卫生部门及其正式疫情通报。
3. 各个国家疾控或公共卫生机构：CDC、NCDC、国家传染病研究机构及其监测周报。
4. 正式监测系统：例如 DGHS 日报、IDWR、JIHS 等由卫生主管部门或疾控机构维护的公开监测产品。
5. 区域公共卫生机构：PAHO、ECDC 及其他区域卫生机构的形势报告、周报和预警。

## 补充来源

在优先来源未发现报告期内符合规则的可核实事件时，可继续检索以下来源，并按证据处理规则核实：

- 国际公共卫生信息平台：CIDRAP、ReliefWeb。
- 权威通讯社和当地正规媒体：Reuters、BERNAMA、Philstar 等。
- 媒体所转引的卫生主管部门、疾控机构或医疗卫生机构原始通报。
- 各个国家的大型疾病传染病疫情新闻报告网站或大型媒体平台。(自行搜索到网址去查询)

媒体和信息平台仅可作为线索或补充来源。若不能取得官方交叉核实，必须标注“媒体报道，待权威来源核实”，且不得将其作为已核实病例、死亡或排序事实。
