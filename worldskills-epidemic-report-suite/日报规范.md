# 世界技能大赛疫情监测日报生成规范

本规范仅适用于 `daily` 模式生成的 Word 日报。与 `references/daily-report.md` 或 `references/official-document-format.md` 存在冲突时，以本规范为准。Excel 证据底表不套用本版式。

## 一、监测范围与统计口径

1. 国家和地区总数必须从当前有效监测名单动态计算，不得在正文中硬编码旧数量。
2. 当前名单应覆盖 120 个国家和地区；正文、底表和检索记录中的数量必须保持一致。名单后续调整时，以实际有效名单数量为准。
3. “当日有更新”是指疫情数据、风险状态或官方通报相较上一版日报发生变化，不要求信息发布日期必须是报告生成当天。
4. 所有病例数、死亡数、暴发数等数据必须注明统计截止日期，并采用查询时能够获得的最新官方数据。
5. 日报必须结合上一版日报和历史底表识别变化，不得仅根据当天抓取结果独立生成。

## 二、报告内容结构

日报按照以下顺序编排：

1. 报告标题。
2. 报告日期。
3. 检索说明。
4. `一、近期赛事相关国家和地区疫情总体概况`。
5. `二、当日新增及变化疫情动态`。
6. `三、其他未更新传染病疫情`。
7. `四、对上海市传染病输入风险综合研判`，并在研判基础上提出防控建议。
8. `附：信息来源`。

“检索说明”仅简要说明监测范围、监测时间窗、数据来源类型和比较基线。不得写入文件扫描数量、网站访问成功率、超时情况、证书错误或爬虫处理过程。

## 三、总体概况写作要求

1. 总体概况必须直接描述近期疫情形势，不得以数据查验过程、访问情况或技术性缺口作为主要内容。
2. 应概括近期需要重点关注的国家、疾病和传播趋势。
3. 对此前未检出、但本期首次发现的新发突发疫情，应单独说明。
4. 总体概况中列出的每一项重点疫情，必须在“当日新增及变化疫情动态”中设置对应内容。
5. 不得出现总体概况提到某项重点疫情、正文却没有数据或分析支撑的情况。
6. “未发现新增信息”不得表述为“当地无疫情”。

## 四、疫情动态编排要求

1. “当日新增及变化疫情动态”优先排列相较上一版日报发生变化的疫情。
2. 每项疫情原则上按照“国家或地区＋疾病名称”设置二级标题。
3. 每项内容至少说明：
   - 最新数据及统计截止日期；
   - 与上一版日报相比的变化；
   - 当前疫情状态或趋势；
   - 数据来源；
   - 必要的不确定性说明。
4. 美国麻疹、欧洲多国西尼罗病毒病、刚果（金）埃博拉等重点疫情应分别成节，不得仅放在概括性段落中。
5. 示例性内容不得进入正式报告。例如“XX 国突发人感染 H7N9 事件”等占位文本必须删除，除非已检索到对应真实事件并完成核验。

### 第二部分正文边界

“二、当日新增及变化疫情动态”只呈现疫情本身及其变化，不呈现检索工作流。每个国家或地区—疾病条目只能保留以下内容：最新病例、死亡、暴发或受影响地区等疫情数据；统计截止日期；相较上一版的新增、增量、状态或趋势变化；当前疫情状态；以及会影响解读的必要不确定性说明。

以下内容禁止写入本部分正文：文件扫描数量、检索范围或检索国家数量、访问成功/失败、网页或网站打不开、搜索关键词、检索步骤、来源筛选过程、跨来源比对过程、去重或冲突处理、证据链或覆盖状态、模型或作者的思考过程、报告生成过程，以及“本次检索发现/经过核验/根据搜索结果”等工作流叙述。需要保留的来源机构、材料标题、发布日期、访问日期和链接，统一放入“附：信息来源”及 Excel 证据底表；不得用来源说明替代疫情事实。

若某条材料只能说明检索过程而不能支撑具体疫情事实，不得进入第二部分；应删除该条，或改写为有明确数据、日期和疫情状态的事实表述。无实质变化时，仅使用“本轮未发现符合报告阈值的新变化”等结果性表述，不得解释检索过程。

## 五、未更新疫情处理

1. 较上一版日报无数据变化的疫情统一放入“其他未更新传染病疫情”。
2. 必须明确列出国家或地区名称和疾病名称，不得仅写“其他多国疫情暂无更新”。
3. 可以简要注明最近一次数据日期，但不得把历史数据表述为本期新增。

## 六、数据来源要求

1. 正文中的每项疫情数据必须能够追溯到具体信息源。
2. 刚果（金）埃博拉疫情优先使用刚果（金）卫生部门或国家公共卫生研究院 INSP 发布的每日疫情形势报告。
3. WHO 区域概览可用于交叉核验，但不得在国家日更报告可获得时替代国家级最新数据。
4. HealthMap 仅作为线索来源。未经官方机构或可信原始来源核验的 HealthMap 信息不得写成正式疫情事实。
5. “信息来源”必须覆盖正文使用的全部数据，不得只列部分主要来源。
6. 信息来源部分必须另起一页。
7. 来源条目至少包含机构名称、材料标题、数据或发布日期、访问日期及可访问链接。

刚果（金）埃博拉国家级日更材料可从 INSP 入口开始核验，例如：`https://insp.cd/sitrep-n113-mvebdb-04-09-2026/`。示例链接用于定位发布栏目，不得替代本轮对最新报告的实时检索。

## 七、Word 文档格式

1. 页面左右页边距均为 28 mm。
2. 标题文字前保留两个全角空格，使用 2 号方正小标宋简体（22 pt），不加粗，单倍行距，居中排列。
3. 报告日期单独置于标题下方，格式为“（YYYY年M月D日）”，月份和日期不补零；使用 3 号楷体_GB2312（16 pt）、加粗并居中。
4. 日报默认不设置主送单位和文末落款；用户明确要求公文报送版时，再按照公文模板增加。
5. 正文使用 3 号仿宋_GB2312（16 pt），固定值 27 pt 行距，段前段后均为 0，首行缩进 2 字符，两端对齐。
6. 一级标题使用 3 号黑体（16 pt），不额外加粗，格式为“一、二、三、……”。
7. 二级标题使用 3 号楷体_GB2312（16 pt）并加粗，格式为“（一）（二）（三）……”。
8. 三级标题使用 3 号仿宋_GB2312（16 pt），格式为“1. 2. 3.……”。
9. 各级正文标题前空两格。优先设置 `w:firstLineChars="200"`，不得用普通或全角空格模拟。
10. 标题和正文不得保留黄色高亮、删除线、批注气泡或修订标记。
11. 不得通过“全部接受修订”机械生成定稿。删除线可能代表删除意见，必须根据上下文落实后生成无审阅痕迹的清洁版本。

## 八、生成前验收

交付前必须检查：

- 国家和地区数量是否与当前名单一致；
- 总体概况中的重点疫情是否均有正文对应章节；
- 有更新和无更新疫情是否根据上一版日报正确分类；
- 每个数值是否具有统计截止日期和可追溯来源；
- 刚果（金）埃博拉是否优先核验国家级日更报告；
- 总体概况是否删除了技术性查验过程；
- 信息来源是否另起一页并覆盖正文全部数据；
- 是否删除示例文字、空白批注、黄色高亮、删除线和全部修订痕迹；
- 字体、字号、标题层级、缩进、行距和页边距是否符合本规范。
