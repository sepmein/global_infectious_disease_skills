# 报告规则

## 固定范围

- 报告名称：世界技能大赛参赛国家和地区重点传染病疫情报告。
- 监测期：2026-08-01 至 2026-09-04。
- 覆盖对象：名单文件中的所有参赛国家和地区。
- 输出重点：近期疫情事实与可追溯证据。

## 疾病纳入条件

满足以下任一条件时纳入底表和/或正文：

- 高发或持续高负担；
- 暴发；
- 异常增加；
- 新发或少见病例；
- 跨国家、跨区域扩散；
- 高病死率或其他严重后果；
- 与国际旅行密切相关。

国家级周报、形势通报、暴发新闻和监测数据中发现的所有疾病均应按本节纳入条件审查。`重点病种检索配置` 表只确定需额外定向检索和优先复核的病种；表外疾病只要有明确的高发、暴发、异常上升、新发、跨区域扩散或高病死率信号，必须纳入底表并记录依据。疾病分类由本轮官方疾病术语资料自动判定。

## 重点国家排序

最多列出 10 个重点国家或地区。按以下优先级综合判断：

1. 报告期病例数、发病率或受影响地域范围；
2. 与前期、历史基线或连续周数据相比的增速；
3. 病死率、住院负担或官方宣布的严重程度；
4. 明确的跨境传播、跨区域扩散或国际关注事件。

无可比基线时，不对增速作数值化判断。缺少病例或死亡数时，不以“无数据”推断低优先级。

## 明细底表字段

每行代表一个“国家/地区-病种-事件或监测信号”组合，至少包含：

主表表头必须严格按下表顺序使用，不增加扩展列；详细来源、检索日志和数据限制另设独立工作表。

| 字段 | 填写规则 |
| --- | --- |
| 国家/地区 | 与名单文件一致的地区代码、英文名称和中文标准名称。 |
| 重点疾病 | 标准疾病名称；必要时写明病原体或亚型。 |
| 近期疫情情况 | 简要描述地点、时间、趋势和事件状态。 |
| 疫情性质 | 高发、暴发、异常上升、新发、跨区域扩散或高病死率等。 |
| 病例 | 写明数量及疑似、确诊、累计或期间新增等口径。 |
| 死亡数 | 写明数量及统计口径；不可获得时写“未检索到可核实数字”。 |
| 最近更新时间 | 来源中最新的发布日期、报告日期或数据截至日期。 |
| 信息来源 | 机构名称、标题、URL、发布日期或数据截至日期和访问日期。 |
| 建议关注程度 | 高、中、低；依据病例数、趋势、严重后果和跨区域扩散等事实填写。 |
| 数据限制 | 可选，记录口径差异、缺失值或仅有聚合数据等。 |

## 正文结构

1. 执行摘要：报告期、覆盖国家数、纳入事件数、重点国家数和主要疾病类别。
2. 重点国家：最多 10 个国家。表头严格为“国家/地区、重点疾病、近期疫情情况、疫情性质”；排序事实和关注程度放在相邻文字说明，不写入该表新增列。
3. 重点疫情：按四个疾病类别组织。每种疾病最多一个小表，表头严格为“疾病、重点国家、近期疫情情况、趋势判断、与赛事相关性”。

“与赛事相关性”概述该疾病与国际旅行、跨境活动或人员聚集相关的公开事实和关注依据。
